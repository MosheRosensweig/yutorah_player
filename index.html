📱 How to use on iPhone (Safari) or Android
🍎 iPhone / iPad (Safari):
  1. Easiest: If your Mac & iPhone use the same iCloud account, drag the bookmark on your Mac and it will automatically sync to your iPhone Safari favorites!
  2. Directly on iPhone: Tap the 📋 Copy Code for Mobile button above.
  3. Tap Safari's Share button (⎋) → Add Bookmark → Name it YUTorah Enhanced → tap Save.
  4. Tap the Bookmarks icon (📖) → Edit → tap YUTorah Enhanced → delete the URL, paste the code, and tap Done.
  5. To listen: On any YUTorah shiur page, tap 📖 → tap YUTorah Enhanced!
🤖 Android (Chrome):
  1. Tap 📋 Copy Code for Mobile above.
  2. Bookmark this page (tap 3 dots → ⭐) and name it YUTorah Enhanced.
  3. Go to Bookmarks → tap 3 dots next to it → Edit → delete URL and paste code.
  4. To listen: On YUTorah, tap the address bar, type YUTorah Enhanced, and tap the search result with the star/bookmark icon!
